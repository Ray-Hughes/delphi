The first time you open it

Delphi is not signed with a paid developer certificate yet, so both systems will stop you once and ask. This is expected, and it is a one time step: after the first launch it opens like anything else.

  1. Open the downloaded .dmg and drag Delphi into Applications.
  2. In Applications, right click Delphi and choose Open. Do not double click it the first time: double clicking offers only a Cancel button, while right click and Open gives you the button that lets it through.
  3. Choose Open in the dialog. macOS remembers, so every launch after this is a normal one.

If macOS says the app is damaged, it is not. That message means the quarantine flag survived the copy. Clear it with:
xattr -dr com.apple.quarantine /Applications/Delphi.app

  1. Run the downloaded Delphi-Setup.exe.
  2. Windows SmartScreen will show a blue box saying it protected your PC. Click More info, then Run anyway. The Run anyway button only appears after More info, which is why the box looks like a dead end.
  3. Follow the installer. It installs for your user only, so it never asks for administrator rights.

What it does

Projects, not one long list

Past thirty items a flat task list stops telling you which entries belong to the same piece of work. Each project holds its own tasks, notes and links.

Your agents remember

Claude Code and GitHub Copilot read and write it over MCP, so what one of them works out is still there for the next session, and for the other one.

It stays on your machine

One SQLite file. Nothing is uploaded, there is no account, and search runs locally against a model on your own computer.

Connect an AI agent

Delphi ships an MCP server, so any agent that speaks MCP can use it, and several can share one store. Open Delphi, then run the connector for your system from the folder it was installed in. 

macOS      bash install/mcp.sh
Windows    powershell -ExecutionPolicy Bypass -File install\mcp.ps1

Restart your editor afterwards. MCP servers are loaded at startup, so one registered mid session does not appear until the editor restarts. That is the single most common reason people think the connection failed.

Requirements

macOS 11 or newer, on Apple Silicon or Intel. Windows 10 or 11, 64 bit. Nothing else: the installers carry everything the app needs.

Node is needed only to connect an AI agent, because the editor launches the MCP server with its own Node rather than with the app. Local search is sharper with Ollama running, and falls back to a lexical search rather than disappearing when it is not.
