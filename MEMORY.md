at the top of its section. This file is the map; the detail belongs in delphi's own
notes table, which is searchable through `search`, `oracle_ask` and `oracle_context`.

otherwise have to rediscover something, it belongs here.

## Standing instructions

- **No em dashes or en dashes anywhere.** Plain hyphens only. Applies to prose, code
  comments, commit messages, generated documents and chat. Reaffirmed 2026-08-12.
- Do not commit or push unless asked. If the repo is on its default branch, branch first.
- Check delphi's notes before searching a repository. A previous session may have
  already worked the answer out.
